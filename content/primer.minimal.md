> **Harness primer.** Managed by [magik-harness](https://github.com/elendil-tech/magik-harness); it is replaced in place on upgrade, so keep your own notes outside the markers.

Work in a closed loop: orient (`git status`; `git pull --ff-only` if behind), implement, verify locally, get a human's approval where taste is involved, ship (PR, watch CI, fix), clean up. Done means merged, checks green and the workspace tidy, not "code written". Cloud-save on pause with `git commit -m "wip: <checkpoint> [skip ci]"` then `git push`, and never `git stash` across worktrees. Load the `agentic-e2e-loop` skill for the procedure, `harness` for what else this install can do (a vault with a knowledge base and memory: `magik-harness install --profile knowledge --vault <dir>`), and `harness-fit` to bring this project in line with the harness (an older setup, drift, after an upgrade).
